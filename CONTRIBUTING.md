# Mitarbeiten an TakeAdmin

Jeder darf mitarbeiten! Damit alles nachvollziehbar bleibt, gelten feste Regeln.

## Ablauf
1. **Forke** dieses Repository.
2. Erstelle einen **Branch** fuer deine Aenderung (`fix/...`, `feature/...`).
3. Mache deine Aenderung und **teste sie selbst**.
4. Oeffne einen **Pull Request** gegen `docs` und fuelle die Vorlage **vollstaendig** aus - beschreibe **genau, was du gemacht hast**.
5. Ein Maintainer **prueft und reviewed** deinen PR. Erst nach **Freigabe (mind. 1 Review)** wird gemerged.

## Regeln
- Direkt auf `docs` pushen ist gesperrt - alles laeuft ueber Pull Requests.
- Jeder PR braucht **mindestens eine Freigabe** und muss offene Kommentare aufloesen.
- Beschreibe in Issues und PRs **immer genau, was gemacht wurde / werden soll**.
- Keine Secrets (Discord-Webhooks, Tokens) committen.
